# Core loop

## Chapter loop (StS-style — Jonathan lock)

1. **Chapter start:** the **chapter boss is announced** (name / threat tags / environment). Player sees the target before spending.
2. **Atelier shop** (you are the **owner / clothier** — Phase-1 = `own_basic`) → reshape material deck (buy / sell) using **your** pool; player skills (Later owners) like free reroll / income floor apply here.
3. **Craft & task** — clients / side tasks; craft gear toward the announced boss.
4. **Shop** again (repeat shop → craft/task → shop) until the chapter clock / node count ends.
5. **Boss fight** with the prepared deck + crafted gear.
6. Next chapter (harder boss announced at its start).

Goal: adjust the deck knowing the boss (StS-style). Different **player owners** (Later) change your material access and skills (Balatro-style character fantasy).

## Single client beat (inside craft & task)

1. **Client** arrives with a clear threat.
2. Select **materials** from deck (multi-stack into construction slots).
3. Combine **Construction + 1..N Materials + 0..1 Enchantment**.
4. Resolver: stats + powers; **neg syn skipped** on rare/legendary; **outlook** = highest `outlook_order` (negs beat peers when live).
5. **Adventure simulation** — short report.
6. **Result** → gold, materials, reputation; scars Later.

## Phase-1 ship spine

One loop UI: client brief → craft → adventure report → atelier shop, as **`own_basic`**, with chapter boss known at chapter start.

Defer encyclopedia, special clients, multi-owner unlocks, and parallel meta until that holds.
