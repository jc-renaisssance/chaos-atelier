# Core loop

1. **Client** (adventurer) arrives with a clear threat (enemy + environment).
2. Select **materials** from deck / inventory (**budget-limited**).
3. Combine **Material + Construction + Enchantment**.
4. Final equipment receives **stats + special powers** from tag combinations (or unique named gear from rare recipes).
5. **Adventure simulation** runs — short report of events vs the enemy.
6. **Result** → gold, new materials, reputation, possible permanent scars / upgrades.
7. **Shop phase:** spend budget on new materials, staff, or upgrades.
8. Repeat with escalating clients → **boss** monster clients.

## Phase-1 loop (locked spine)
Ship **only**: client → craft → sim report → shop.

Defer boss ladder depth, encyclopedia full illos, named recipes, and parallel special-client content until that loop holds.
