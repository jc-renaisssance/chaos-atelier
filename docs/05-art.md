# Art strategy

## AI-friendly pipeline
- **Modular** material / construction / enchantment **icons** (inventory cards)
- **Outlook outcomes**: construction × synergy looks (pos **and** neg) — see [15-outlook-gen-list](15-outlook-gen-list.md)
- **Shop owner** chrome — see [16-shop-owners](16-shop-owners.md); Phase-1 = basic only
- **Customer portraits**
- **Selective full illustrations** for Encyclopedia discoveries only

## Outlook contract (Jonathan lock)
- Gen **combination** art per construction × outlook synergy
- **Plain / default** color when no synergy outlook fires
- Each synergy (including **negatives**) has an **outlook_order**; final garment uses **only the highest order**
- Explicit combo id list in `15` before any mass gen; Finance stamps Phase-1 batch size (**50** garment + optional `shop_own_basic`)

## Locks (carry DARE lessons)
- Stamp **icon grain + tag color grammar** before mass content
- **No gens on locked icons**
- Hard **gen budget** before first icon batch (Finance stamps Phase-1 envelope)
- Do not wire modular icons in Client until Design stamps socket / size (placeholders OK to prove craft → report)
- **No multi-owner shop art** until stamped Later

## Out of scope for Phase-1 art
Boss client full sets, shop chrome polish beyond basic owner, everyday Encyclopedia full illos, full outlook matrix incl. all neg looks, voodoo/tech owner sets.
