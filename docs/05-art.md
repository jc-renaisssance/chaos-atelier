# Art strategy

## AI-friendly pipeline
- **Modular** material / construction / enchantment **icons**
- **Customer portraits**
- **Selective full illustrations** for Encyclopedia discoveries only

## Locks (carry DARE lessons)
- Stamp **icon grain + tag color grammar** before mass content
- **No gens on locked icons**
- Hard **gen budget** before first icon batch (Finance stamps Phase-1 envelope)
- Do not wire modular icons in Client until Design stamps socket / size (placeholders OK to prove craft → report)

## Out of scope for Phase-1 art
Boss client full sets, shop chrome polish, everyday Encyclopedia full illos.
